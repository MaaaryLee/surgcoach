# The 15 trials every batch uses, so the C, D and event families all cover the
# same videos and can be compared record against record for one trial.
#
# One list in one file because there are now three readers -- stratified_trials.ps1
# for the Windows C/D runners, stratified_trials.sh for the cluster sbatch scripts,
# and anything checking coverage. Two copies of a list like this drift, and the
# drift is silent: a batch simply covers different videos than the batch it is
# being compared with.
#
# Chosen to span each task's GRS range rather than taken alphabetically. The
# earlier selection was B001-B004 plus C001 per task, which is just the front of
# the file listing: 13 of those 15 scored 17 or below out of 30, all five Suturing
# trials were novice, and no expert trial appeared anywhere. Two templates cannot
# do their job on a sample like that -- C7 has five supervision levels and used one
# for all 15 records, and D5 is asked to name a strongest skill where none of the
# trials has a strength to name.
#
# The spread also decouples skill_level from grs_total, which the old selection
# could not: Suturing_D004 is an expert scoring 8/30 and Knot_Tying_H004 a novice
# scoring 22/30. Those cases test whether the model reasons from the scores or
# just parrots the self-reported experience label.
#
# Columns: task  trial_id  skill_level  grs_total  subset
# skill_level and grs_total are here for reading and for coverage checks; the
# runners take them from meta_file at generation time, never from this file.
#
# subset "core" marks the 7 trials used when a smaller batch is wanted. All 15
# give 60 event records; the core 7 give 31, at roughly 2.8 minutes each locally.
#
# Which 7 is not arbitrary, and not the first 7 either. Truncating the list would
# have dropped Needle_Passing entirely and taken the GRS range down to 8-19, which
# is close to the flaw that forced this list to be rewritten in the first place.
# The core keeps:
#   all three tasks                       Suturing 3, Knot_Tying 2, Needle_Passing 2
#   the full score range                  GRS 6, 7, 8, 13, 22, 23, 30
#   all three skill labels                E x2, N x3, I x2
#   both skill/GRS decoupling cases       Suturing_D004 is an expert at 8/30 and
#                                         Knot_Tying_H004 a novice at 22/30, the
#                                         two trials that test whether the model
#                                         reasons from the scores or parrots the
#                                         self-reported label
# Dropped trials are the redundant middles: Suturing_E004 and Knot_Tying_E002 both
# sit at 19 beside Needle_Passing_B004, and Needle_Passing_B004 yields 1 event.
