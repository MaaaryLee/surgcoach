# Generated QA Datasets

Real, annotation-only QA pairs generated by `scripts/run_annotation_qa_jigsaws.py` on the lab GPU cluster. No frames were sent to the model; every answer is model-written and grounded solely in JIGSAWS annotations. Every record carries full provenance (`model.backend: "real"`, exact prompt, raw model output including thinking, source annotation values, validation status).

Notes:

- Generated with the prompt stack at commit `26cb846` (before the D1-template simplification and field-name-leakage rule in `7721df0` were live on the cluster).
